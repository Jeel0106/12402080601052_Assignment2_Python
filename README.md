# Programming with Python - Assignment 2

Complete Assignment 2 with 10 Python programs and output images.

All programs are written at beginner level and contain no comments.

## Programs

Program1.py - Regex-Based Email Intelligence Extractor
Program2.py - Offline Web Scraping Ranker
Program3.py - MySQL Student-Course Analytics Engine
Program4.py - SQL Join Query Builder and Validator
Program5.py - Tkinter Contact Manager with MySQL Backend
Program6.py - Log Anomaly Detector using Sliding Window
Program7.py - Generator-Based JSON ETL Pipeline
Program8.py - Matrix Path Optimizer with Dynamic Programming
Program9.py - OOP Inventory Merger with Operator Overloading
Program10.py - Python Data Visualization Dashboard Exporter

Each Program has a matching ProgramN.jpeg output file.

Python 3.10 or above is required. Program 3 and Program 5 need mysql-connector-python. Program 10 needs pandas and matplotlib.
